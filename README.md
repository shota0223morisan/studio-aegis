# Studio Aegis

DAW 以外の制作まわりを 1 か所に集約する、個人用の音楽制作ハブ(Mac アプリ)。
**取引先 → 曲** ごとに、先方からの指示(音源の添付つき)・こちらのメモ・アイデア(Notion)・ファイルをまとめて管理。ウィンドウの左には **Spotify / Amazon(MP3)/ Splice / Web をタブで切り替えられるパネル**、右に作業場(Lyric Machine と同じ構成)。

> 「DAW と Studio Aegis の 2 つだけ開いていればいい」状態がゴール。姉妹アプリ: Lyric Machine

**Mac の中だけで完結**します。アカウント登録・パスワード・サーバーは不要で、データはすべてこの Mac に保存されます。

## インストール

1. [Releases](../../releases/latest) から dmg をダウンロード
   - Apple Silicon(M1 以降)→ `Studio-Aegis-apple-silicon.dmg` / Intel Mac → `Studio-Aegis-intel.dmg`
2. dmg を開いて Studio Aegis を「アプリケーション」へドラッグ
3. 初回だけ「開けません」と出るので、**システム設定 → プライバシーとセキュリティ** →「このまま開く」(Apple の有料署名をしていない個人用アプリのため)

**更新**: 新しいバージョンが出るとアプリ上部にお知らせが出ます。dmg を入れ直す(「置き換える」)だけで、データはそのまま残ります。

## 画面

```
┌──────────── 左パネル ────────────┬────────────── 作業場 ──────────────┐
│ [Spotify][Amazon][Splice][Web]   │ ◧ STUDIO AEGIS  01 ワーク 02 取引先 03 設定  ●●●●●●● │
│ (Web のときはアドレスバー)        ├──────────┬──────────────────────────┤
│                                  │ 取引先     │ ▌新曲「〇〇」 NOW WORKING     │
│  open.spotify.com / amazon.co.jp │  └ 曲      │ 01 先方からの指示 + 添付音源   │
│  splice.com / Google など         │  └ 曲      │ 02 こちらのメモ               │
│                                  │            │ 03 アイデア(Notion)          │
│                                  │            │ 04 ファイル                   │
└──────────────────────────────────┴──────────┴──────────────────────────┘
```

- **左パネル** — タブで切り替え(⌘1〜⌘4、表示切り替え ⌘⇧L、境界をドラッグで幅を変更)。どのタブもログインは保存される
  - **Spotify** — 検索・プレイリスト操作。音は Mac の Spotify アプリで鳴らす(画面下「デバイスに接続」で Mac を選ぶとリモコンになる。アプリ内蔵ブラウザには Spotify の再生用 DRM がないため)
  - **Amazon** — Amazon の MP3 ストア(DRM フリーの MP3 を購入・ダウンロード)
  - **Splice** — サンプル探し
  - **Web** — 調べ物用のブラウザ。アドレスバーに URL か検索ワード(Google)。「Chrome ↗」「Safari ↗」で今のページをそれぞれのブラウザで開ける
  - 作業場の中のリンク(先方からの指示に貼った URL、Notion のアイデアなど)も左パネルで開く
- **取引先 → 曲** — 左のサイドバーに取引先、その下に曲。取引先ごとに「取引先メモ」(担当・好み・NG・納品形式など)。曲は取引先の付け替えも可能
- **曲の作業場**(各欄は書いた量に合わせて伸び縮みする)
  - **01 先方からの指示** — Markdown(編集/表示)、自動保存。**添付音源**(先方からの参考音源・デモ)をドラッグ&ドロップで添付、その場で再生
  - **02 こちらのメモ** — 構成・進行など。Markdown、自動保存
  - **03 アイデア** — Notion の「🎛 制作アイディア」をカードで表示(要素・ジャンル・状態で絞り込み、検索、クリックで Notion を左パネルに表示)
  - **04 ファイル** — 完成版 / その他
- **ワーク** — 最近さわった曲の一覧と「＋ 新しい曲」
- **設定** — デザインテーマ、Notion 連携、データの保存場所・バックアップ、アップデート確認

## Notion(アイデア)を使う

設定画面の手順どおりに:

1. [Notion のインテグレーション](https://www.notion.so/profile/integrations)で内部インテグレーションを作り、トークン(`ntn_…`)をコピー(Lyric Machine で使っているトークンでも OK)
2. Notion で「🎛 制作アイディア」を開き、右上の「…」→「接続」でそのインテグレーションを追加
3. 設定画面にトークンを貼って「保存して接続を確認」(データベースの URL は最初から入っています)

Notion 側は読むだけで変更しません。最後に読み込んだ内容はアプリ内に残るので、オフラインでも見られます。

## デザインテーマ

右上の色の丸をクリックするだけでいつでも切り替えられます(設定画面には見本付きの一覧)。最初は MECHA。フォントはアプリに同梱しているのでオフラインでも表示されます。

| テーマ | 雰囲気 |
|---|---|
| STUDIO | シンプル。Mac のライト/ダークに合わせる |
| MECHA | Lyric Machine とおそろいの HUD。シアン×マゼンタ、角のブラケット |
| ROCK | ライブポスター。赤×黒、ハーフトーン、太いコンデンス書体、ずらし影 |
| METAL | クローム×漆黒×ブラッドレッド。ブラックレターのロゴ、ヘアライン金属 |
| ELECTRO | クラブの照明。ネオングラデーション、すりガラス、ゆっくり動く光 |
| CYBERPUNK | 夜の街の HUD。イエロー×シアン、走査線、角を落としたパネル、グリッチ |
| JPOP | パステル×キラキラ。まるっこい文字、ステッカー風カード、手書き風ロゴ |

## データとバックアップ

- 保存場所: `~/Library/Application Support/Studio Aegis/data`(`aegis.db` と `files/`)。普段は触らなくて OK
- Time Machine を使っていれば自動でバックアップされます
- 手動で残したいときは、メニュー「ファイル → バックアップを書き出す…」(設定画面にもボタンあり)

## Splice について(調査結果)

| 方法 | 結果 |
|---|---|
| 公式 API / 埋め込み機能 | 外部アプリ向けの公開 API・embed はなし(2026 年時点で提供されているのは AI ツール向けの「Splice MCP Server」のみ) |
| ページ内に iframe で埋め込み | splice.com は全ページで `X-Frame-Options: SAMEORIGIN` / `frame-ancestors 'self'` を返すため不可 |
| **アプリ内の独立した Web ビューで表示** | **可能(採用)**。iframe ではなく通常のページとして開くので制限に当たらない |

## 開発

```
web/       画面(React + Vite + TypeScript)
desktop/   Mac アプリ(Electron)
  src/main.js        ウィンドウ(左パネル: Spotify / Amazon / Splice / Web、右: 作業場)・メニュー
  src/server/        ローカルサーバー(127.0.0.1 のみ。SQLite + ファイル保存、Notion 連携)
```

```bash
npm install && (cd desktop && npm install)
npm run desktop      # 画面をビルドしてアプリを起動
```

`desktop/` か `web/` を変更して push すると、GitHub Actions(macOS)が dmg をビルドして Release に添付します(`.github/workflows/desktop.yml`)。バージョンは `desktop/package.json` の `version` で、上げるとアプリに更新のお知らせが出ます。

- ローカルサーバーは 127.0.0.1 のみで待ち受け、起動ごとに生成する秘密の Cookie を持つアプリのウィンドウ以外からの API アクセスを拒否します
- 並び順は API 側で `sort=updated | deadline | pinned` を用意済み(UI は「最終更新順」のみ有効)
