# Studio Aegis

DAW 以外の制作まわりを 1 か所に集約する、個人用の音楽制作ハブ(Mac アプリ)。
**取引先 → 曲** ごとに、**5 ステージの制作フロー**(DECODE → FRAME → LAYER → MIXING → SHIP)に沿って進めるだけでトラックが完成する作りです。真ん中が作業場で、左右のパネルに Splice / Suno / Web / Amazon(MP3)と YouTube Music / Spotify をタブで表示します。AI(契約中の Claude のサブスク)が分析・MIDI 生成で加速し、ステージの鍵が寄り道を止めます。

> 「DAW と Studio Aegis の 2 つだけ開いていればいい」状態がゴール。姉妹アプリ: Lyric Machine

**Mac の中だけで完結**します。アカウント登録・パスワード・サーバーは不要で、データはすべてこの Mac に保存されます。

## インストール

1. [Releases](../../releases/latest) から dmg をダウンロード
   - Apple Silicon(M1 以降)→ `Studio-Aegis-apple-silicon.dmg` / Intel Mac → `Studio-Aegis-intel.dmg`
2. dmg を開いて Studio Aegis を「アプリケーション」へドラッグ
3. 初回だけ「開けません」と出るので、**システム設定 → プライバシーとセキュリティ** →「このまま開く」(Apple の有料署名をしていない個人用アプリのため)

**更新**: 新しいバージョンが出るとアプリ上部にお知らせが出ます。**「⬆ 今すぐ更新」を押すだけで、自動でダウンロード → 確認 → 入れ替え → 再起動**します(設定画面・メニュー「Studio Aegis → アップデートを確認…」からも)。データはそのまま残ります。
- 「アプリケーション」フォルダに入れたアプリで使えます(dmg から直接開いている場合は、先にアプリケーションへ入れてください)
- ダウンロードしたファイルは、GitHub の sha256・アプリの ID・バージョン・署名を確かめてから入れ替えます
- v0.5.0 以前からは、一度だけ dmg で v0.6.0 を入れてください(アプリ内更新は v0.6.0 から)

### 左右のパネル
- 既定は **左 = Splice / Suno / Web / Amazon、右 = YouTube Music / Spotify**。どのタブも反対側へ移せる(⇥ / ⇤、またはタブを右クリック)、**⇄ で左右をまるごと入れ替え**、⟨ ⟩ で畳む(⌘⇧L / ⌘⇧R)。境界をドラッグで幅を変更。タブは ⌘1〜⌘6
- **レイアウト**(作業場右上): LISTEN(プレイヤーを広く)/ BUILD(Splice + 小さいプレイヤー)/ POLISH(プレイヤーだけ)/ FOCUS(両方畳む、⌘⇧F)。ステージが進むと自動で切り替わる(設定でオフにできる)
- **YouTube Music** はアプリ内でそのまま音が出る。**曲の再生は基本ここ**(Notion のアイデア・参考曲・近い曲の「▶ 聴く」を押すと、曲を自動で特定してここで再生)。**Spotify** は検索・操作用(内蔵ブラウザに再生用 DRM がないため、音は Mac の Spotify アプリから。画面下「デバイスに接続」でリモコンになる)
- **Suno** — 波形の生成(アプリ内では作れないので Suno のサイトを表示。AI が Style 欄の文面を作ってコピーできる)
- **ログインのポップアップ**(Notion・Splice・Suno の「Google でログイン」など)は小さな別ウィンドウで開く
- **Google でログイン**(YT Music・Splice・Suno など)— Google はアプリに埋め込まれたブラウザからのログインを断るため、Google のログイン画面のときだけ Firefox として振る舞います
- **Web** — アドレスバーに URL か検索ワード。「Chrome ↗」「Safari ↗」でそれぞれのブラウザで開ける。どのタブもログインは保存される

### 制作フロー(曲ごと)
各欄はタイトルをクリックで畳める(畳んだ状態は覚えておく)。

各ステージに **ミッション・制限時間・クリア条件(EXIT GATE)・AI・自分用メモ** があり、条件を全部満たすと次のステージが開く(**固い鍵**。設定で「ゆるい鍵」= 確認して進めて記録に残す、にも変えられる)。
**クリア条件は「アプリに書く」か「チェックを入れる」のどちらでも OK**(DAW で決めたならチェックだけで進める)。書けば書いたで、下の「書くと得すること」が使える。

| ステージ | やること | 鍵(クリア条件) | 時間 |
|---|---|---|---|
| **01 DECODE** リファレンス解析 | 先方からの指示(音源添付)/ 先方が本当に欲しいものを一言で / **REF SLOTS** 3 曲(▶ 再生中の曲を取り込み、添付音源から BPM・キーを自動解析、活かす所)/ テンポ・ビート感 / **SIMILAR**: AI が音楽的に近い曲を 8 曲(キーは考慮しない) | 指示が入っている・一言・3 曲・活かす所 ×3・テンポ | 30 分 |
| **02 FRAME** 骨組み | 構成(テンプレートあり)/ 何から作るか / コード進行 / **CORE 3**(ドラム・ベース・ギター or ピアノ、どの曲のどこを参考に)/ MIDI / Notion 制作アイディア / **PARKING**(ミックスしたくなったらメモして先へ → MIXING のチェック項目になる) | 構成・最初のパート・コード・3 パート仮決め | 1.5 時間 |
| **03 LAYER** 肉付け | **LAYER MAP**(上物ごとに参考曲と参考にする所)/ MIDI / Notion 制作アイディア / PARKING | 上物 1 つ以上・すべてに参考・すべて入れた | 2 時間 |
| **04 MIXING** ミックス | Notion「🎚️ Mixing Tips」を表示。**書き出し前チェックリスト**を曲ごとにチェック(+ 保留していたこと) | チェックリスト全部 | 1 時間 |
| **05 SHIP** 書き出し・提出 | mp3 を入れて **SUBMIT** → TRACK COMPLETE。ステージごとの時間ログ | mp3 | — |

- **コード進行の一言入力**: `4536` / `453メジャー6` / `6フラット7フラット1` / `IV-V-iii-vi` / `Am F C G` / `2m7 5 1` など。`サビ 4536 A: 1645 B 2536` でセクションごとに振り分け。基本はダイアトニック(1=I 2=IIm 3=IIIm 4=IV 5=V 6=VIm 7=VIIm♭5、♭3・♭6・♭7 はメジャー)
- **書くと得すること**: コード進行 → その場で **＋ベース / ＋ピアノ / ＋ストリングス / ＋アルペジオ** の MIDI を一発生成(構成の小節数・キー・テンポに合わせる) / テンポ → 参考曲のテンポと並べて比較 / CORE 3 の「参考にする所」→ ✦ AI でそのパートの MIDI
- **曲まるごと読込**: DAW から書き出した曲の MIDI を入れると、トラック名から楽器を判別して **楽器ごとに MIDI 倉庫へ**。テンポ・キー・各セクションのコード進行・CORE 3・上物を自動で埋める(チェックも付く)
- **制限時間**: ▶ START で計測(アプリを閉じても進む)。超えると通知して「仮で決めて次へ」。時間は設定で変更
- **AEGIS AI**: 曲 × ステージごとの会話。曲の状況(指示・参考曲・構成・コード・メモ)を踏まえて答え、ステージから逸れると引き戻す。ワンタップの質問ボタンつき
- **MIDI**: 楽器・小節数・セクション・希望を選んで **✦ AI で生成**(テンポ・コード・参考曲を踏まえる)。**参考 MIDI** を選ぶと、そのノート割り当て(ドラムマップ)・ノリを踏襲(「ヒューマナイズして」など作り変えも)。≈ で手早くヒューマナイズした版を作る。簡易音源で試聴、**行をそのまま Logic などの DAW へドラッグ**、.mid のダウンロード・読み込みも
- **MIDI 倉庫**(上の「MIDI」): すべての曲の MIDI が楽器別(ドラム・ベース・ピアノ・ギター・ストリングス・ブラス・シンセ…)に溜まる。検索・楽器で絞り込み、別の曲で使う
- サイドバーの曲名の横にステージ番号(提出済みは ✓)

### AI を使う(Claude のサブスク)
Lyric Machine と同じく、この Mac の **Claude Code(`claude` コマンド)** を通して、契約中の Claude のサブスクで動きます(API キー・従量課金なし)。
1. [Claude Code](https://claude.com/claude-code) を入れる
2. ターミナルで `claude` → `/login` でサブスクのアカウントにログイン
3. 設定画面に「Claude Code …」と出れば OK(モデルも選べる)

AI は音源を聴けません。曲名・アーティストの知識と、書いたメモ・解析した BPM を根拠にします。

## Notion(アイデア・Mixing Tips)を使う

設定画面の手順どおりに:

1. [Notion のインテグレーション](https://www.notion.so/profile/integrations)で内部インテグレーションを作り、トークン(`ntn_…`)をコピー(Lyric Machine で使っているトークンでも OK)
2. Notion で「🎛 制作アイディア」と「🎚️ Mixing Tips」を開き、それぞれ右上の「…」→「接続」でそのインテグレーションを追加
3. 設定画面にトークンを貼って「保存して接続を確認」(データベース・ページの URL は最初から入っています)

Mixing Tips の「書き出し前チェックリスト」(チェックボックスの項目)が MIXING の鍵になります。Notion につながっていないときは、同じ内容の内蔵リストを使います。

**アイデアのカードを押すと、その曲(「曲」「アーティスト」)を右の YT Music で「位置(mm:ss)」から再生**します(曲は YouTube Music の検索で自動で特定、2 回目からは即再生)。カード右下の ↗ で Notion のページを開けます。

Notion 側は読むだけで変更しません。最後に読み込んだ内容はアプリ内に残るので、オフラインでも見られます。

## データとバックアップ

- 保存場所: `~/Library/Application Support/Studio Aegis/data`(`aegis.db`・`files/`・`midi/`)。普段は触らなくて OK
- Time Machine を使っていれば自動でバックアップされます
- 手動で残したいときは、メニュー「ファイル → バックアップを書き出す…」(設定画面にもボタンあり)

## Splice について(調査結果)

| 方法 | 結果 |
|---|---|
| 公式 API / 埋め込み機能 | 外部アプリ向けの公開 API・embed はなし(2026 年時点で提供されているのは AI ツール向けの「Splice MCP Server」のみ) |
| ページ内に iframe で埋め込み | splice.com は全ページで `X-Frame-Options: SAMEORIGIN` / `frame-ancestors 'self'` を返すため不可 |
| **アプリ内の独立した Web ビューで表示** | **可能(採用)**。iframe ではなく通常のページとして開くので制限に当たらない |

## 開発

```
web/       画面(React + Vite + TypeScript)
desktop/   Mac アプリ(Electron)
  src/main.js        ウィンドウ(左パネル: Spotify / Amazon / Splice / Web、右: 作業場)・メニュー
  src/server/        ローカルサーバー(127.0.0.1 のみ。SQLite + ファイル保存、Notion 連携)
```

```bash
npm install && (cd desktop && npm install)
npm run desktop      # 画面をビルドしてアプリを起動
```

`desktop/` か `web/` を変更して push すると、GitHub Actions(macOS)が dmg をビルドして Release に添付します(`.github/workflows/desktop.yml`)。バージョンは `desktop/package.json` の `version` で、上げるとアプリに更新のお知らせが出ます。

- ローカルサーバーは 127.0.0.1 のみで待ち受け、起動ごとに生成する秘密の Cookie を持つアプリのウィンドウ以外からの API アクセスを拒否します
- 並び順は API 側で `sort=updated | deadline | pinned` を用意済み(UI は「最終更新順」のみ有効)
